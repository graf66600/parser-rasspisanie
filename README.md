# 📚 Telegram-бот расписания преподавателя (Трипольский)

Умный Telegram-бот, который принимает файлы расписания в формате Excel (`.xlsx` или `.xls`), автоматически находит все пары преподавателя по фамилии **Трипольский** и предмету **Информатика**, и заблаговременно присылает уведомления перед каждым занятием.

## 🚀 Возможности
- 📥 **Приём расписания напрямую в чат:** достаточно перетащить или отправить `.xlsx` / `.xls` файл боту.
- 🔍 **Умный парсинг Excel:** понимает различные структуры расписаний колледжей и вузов (сетки по дням недели, матрицы по группам, построчные списки).
- 🔔 **Автоматические напоминания:** за 15 минут (или любое настроенное время) до начала пары бот отправляет уведомление с указанием аудитории, группы и времени.
- ☀️ **Утренний дайджест:** в 08:00 присылает краткую сводку расписания на текущий день.
- 📅 **Удобные команды:**
  - `/start` — главное меню и статус расписания.
  - `/today` — пары на сегодня.
  - `/tomorrow` — пары на завтра.
  - `/week` — полное расписание на неделю (Пн–Сб).
  - `/bells` — расписание звонков (1–6 пара).
  - `/settings` — настройка времени напоминания (5, 10, 15, 30 минут) и переключение дайджеста.

## 🛠 Установка и запуск

1. **Создайте бота в Telegram:**
   - Откройте диалог с [@BotFather](https://t.me/BotFather).
   - Введите `/newbot`, задайте имя и юзернейм бота.
   - Скопируйте полученный HTTP API токен.

2. **Настройте `.env`:**
   - Создайте файл `.env` в корне проекта (скопировав из `.env.example`):
   ```env
   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```

3. **Запустите бота:**
   ```bash
   npm run dev
   ```
   Или соберите проект для продакшена:
   ```bash
   npm run build
   npm start
   ```

4. **Проверка парсера (без токена):**
   ```bash
   npm run test:parser
   ```

## Исправления

- Убраны совпадения групп по подстроке, подсчёт чужих преподавателей/дисциплин и смешение подгрупп.
- Номер практики и номер лекции считаются отдельно, без циклического возврата к №1.
- Расписание учитывается только в указанную в нём неделю, записи журнала и расписание не удваивают одну пару.
- Для 11фм используется подтверждённая контрольная точка №8, а не прибавление семи к уже накопленному журналу.
- Сохранённые темы и номера не переписываются при загрузке журнала.
- Плановые часы берутся из ведомости независимо от числа тем; статистика разделена по семестрам и подгруппам.
- При выборе темы сохраняется её номер внутри типа занятия, а не номер рекомендованной ранее темы.

## Что требует дополнительного источника

Фотографии — ведомость нагрузки, не календарно-тематический план. Списки тем сохранены, не обрезаны и не дополнены выдуманными темами.
Для окончательного соответствия «дата → номер → тема» нужны КТП и фактический журнал проведённых занятий, включая отмены и замены.
Без заполненной истории предварительная нумерация по доступным данным не доказывает фактически проведённое количество пар.
Ранее ошибочно сохранённые записи не исправляются автоматически: их необходимо сверить с журналом.

# Расписание 02–07.11.2026

Расшифровка фотографий пользователя с ручной сверкой. Это разовый импорт
конкретной недели, а не универсальный OCR-парсер.

Для воспроизведения: `npm run build`, затем
`node src/scripts/photoSchedule/build.cjs` из корня проекта.
Скрипт проверяет схему, уникальность ячеек, группы, среду и восемь пар
Трипольского, затем синхронно записывает JSON в `data/` и `public/data/`.

В строках расшифровки поля разделяются `|`:
день недели, номер/диапазон пар, ключ предмета, преподаватель,
корпус:аудитория, подгруппа. Отсутствующие на листе сведения остаются пустыми.
Объединённые по вертикали занятия развёрнуты в отдельные пары.
Подпись производственной практики занимает весь день: сохранены все строки
практики, без назначения выдуманного преподавателя.
